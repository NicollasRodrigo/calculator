# 🧮 Calculadora

Calculadora desenvolvida com **React + Vite**, criada para praticar componentes, eventos e lógica de interface.

## 🛠️ Tecnologias

- ⚛️ React
- ⚡ Vite
- 📄 HTML
- 🎨 CSS
- 🟨 JavaScript

## 🚀 Funcionalidades

- Operações matemáticas básicas
- Interface interativa
- Atualização dos valores em tempo real

## ▶️ Como executar

```bash
npm install
npm run dev
```

Depois, abra o endereço informado pelo Vite no navegador.

## 📁 Estrutura

```text
src/       # componentes e lógica da aplicação
public/    # arquivos públicos
README.md  # documentação do projeto
```

## 📚 Objetivo

Projeto desenvolvido como parte dos meus estudos de desenvolvimento front-end, com foco em React e na construção de interfaces interativas.
